# webtest
Aquesta és una primera web bàsica per a cicles de grau superior

# Execució
Un cop obert instal·la el programa git executant la següent comanda: 
$ sudo apt install git

Descarregat el teu primer codi d’un repositori d’internet amb les comandes:
$ mkdir  ~/webtest/.
$ cd ~/webtest/.
$ git clone https://github.com/villaverdejose/webtest.git .

Executa les següents comandes en el mateix ordre que s’indiquen a continuació:
$ sudo chmod +x ~/webtest/dependencies.sh
$ ~/webtest/dependencies.sh
